Changelogs

Stay up to date with the latest improvements to Smart Collection Pro.

May 5, 2026​

  • Improved conditions UI: The condition interface now supports selecting multiple items at once, making it faster to configure conditions and keeping the list cleaner and easier to read and navigate. You can also paste a list of values (one per line) to populate it quickly. This applies to the following conditions:
    • Tag (equal)
    • Product Type (equal)
    • Vendor (equal)
    • Metafield of type text or list of texts (equal)

May 2, 2026​

  • New feature: Folders: You can now create folders to organize your collections. A folder is a virtual collection that groups sub-collections together without creating a Shopify collection on its own. It doesn't contain products directly, doesn't appear in breadcrumbs, and doesn't count toward your collection limit. Folders can only be placed at the root of the hierarchy, and their filters will apply to all their sub-collections. See folder documentation
  • New setting: Collection list navigation: We added a setting to choose how collections are displayed on the home page. By default all collections are shown in a full tree view. You can now switch to a "Root only" mode where only top-level collections are shown initially, making it easier to navigate stores with a large number of collections. Click a collection to reveal its sub-collections. This was designed to play well with folders.
  • Enhanced user interface: We added buttons to quickly create a child collection, both from the collection edit screen and from the collection list rows.

April 29, 2026​

  • New date operators: Added a new operators "is within next X days" for date filters, making it possible to dynamically filter product by date fields or metafields when the date is between today and a number of days in the future.

April 18, 2026​

  • New date operators: Added two new operators "is before" and "is after" for date filters.
  • Enhanced synchronization speed: The collection synchronization has been improved to be faster, notablye for stores with a large catalog or using many time conditions.

April 16, 2026​

  • Added XLSX files to import/export: It's now possible to export XLSX files and use XLSX files for imports. Until now only CSV were supported.

April 10, 2026​

  • Added admin block for collection page: You can now see the status of a collection managed by the app, directly from the Shopify collection page. To do so open any collection, scroll to the bottom of the page, where you will find a button to a add admin blocks.

April 9, 2026​

  • Added metafield value suggestiongs: Metafield of type text now suggest options as you type, making it faster and easier to create condition based on metafield values.
  • Added empty filters on product type: You can now filter products based on whether their product type is empty or not empty

April 8, 2026​

  • Improved product category search: When using the product category filter, the search now returns all available categories, not just the ones already used by products in your store.

April 7, 2026​

  • Added a setting to hide empty collections: We added a setting on the collection grid to hide collections that are empty.

April 2, 2026​

  • Increased collection limits for each plan: The maximum number of collections has been increased across all plans from 20 to 25, 80 to 100, 200 to 250, and 1000 to 2000..
  • Added bulk deletion: You can now select multiple collections and delete them all at once.

April 1, 2026​

  • Added more customization to breadcrumb app block: We added various css variables to help customizing font on the breadcrumb app blocks. See documentation.

March 11, 2026​

  • Added a setting to show a collection carousel: We added a setting on the collection grid allowing to display collections in a scrollable horizontal list.

March 9, 2026​

  • Added option for sub-categories: When using the product category filter, we added an option to let it match all of its sub-categories
  • Product type list: When adding a condition to filter products by product type, it will now display a list of product types to provide auto-completion.

February 26, 2026​

  • Added breadcrumb prefix url: We added a setting to customize the link of the breadcrumb prefix.
  • Added breadcrumb structured data: We added a structured data using the google-recommended JSON-LD format to improve search results on google.

February 13, 2026​

  • Added theme status on homepage: We added on on the app's homepage the list of the app blocks that are currently installed.

January 27, 2026​

  • Colection grid: We made the default background color of the title slightly darker to ensure good readibility of the title. Also added a CSS variable to control it: --scp-cg-title-wrapper-background-color.

January 26, 2026​

  • Collection grid: We added the ability to order the collections either by title or by product count.

January 16, 2026​

  • Collection grid: We fixed the collection grid that was shrinking to minimal size and didn't display images properly on some themes.
  • Product breadcrumb: We fixed the product breadcrumb not always showing the right collection matching the priority list defined in the app settings.

January 2, 2026​

  • Variant title and availability: When adding a condition to filter on variant's title, there will now be a checkbox to force matching variants to be in stock as well.

December 31, 2025​

  • Bug fix: We fixed a bug that prevented collections from being saved properly when one of its sub-collection was deleted from the store.

December 26, 2025​

  • Vendor list: When adding a condition to filter products by vendor, it will now display a list of vendor to provide auto-completion.

December 20, 2025​

  • New synchronization system: We released a new synchronization system that is much faster for large stores. The app can now handle stores of any size. We are migrating stores to the new system little by little to ensure stability for everyone during the process.

December 4, 2025​

  • Breadcrumb customization: Added an option to hide products name from breadcrumbs and improved mobile styling with new customization options for font size and spacing using custom CSS code.

December 1, 2025​

  • Product category filter: You can now filter products based on whether their category is empty or not empty.

November 12, 2025​

  • Breadcrumb settings: Added a new settings page to define priority for breadcrumbs and customize how they appear.
  • Collection breadcrumb customization: You can now change the root label for collection breadcrumbs (defaults to "home").
  • Product breadcrumb app block: Added a new app block for displaying product breadcrumbs in your theme.
  • New filter: Added a new media count filter to select products based on the number of images or media files they have.

October 26, 2025​

  • Import improvements: Enhanced support for importing collections with improved feedback and error messages.

September 19, 2025​

  • Duplicate collection branch: New tool to duplicate a full collection branch (early access)

August 30, 2025​

  • New filter: Added an inventory tracking filter to select products based on whether inventory tracking is enabled or disabled.

August 21, 2025​

  • Nested collections fix: Fixed a bug that prevented parent collections from being properly processed for products at depth 3 or deeper in the hierarchy.

August 15, 2025​

  • Collection grid improvements: Enhanced the collection grid app block with more settings.

August 13, 2025​

  • Product with over 100 variants: Fixed processing for products having more than 100 variants (extra variants were skipped).

August 6, 2025​

  • Settings page fix: Fixed an issue that prevented saving settings.
  • Parent collection picker fix: Fixed the parent collection picker to properly show a modal when no collections are available.
  • Increased collection limits: Raised the maximum number of collections allowed for each plan.

July 21, 2025​

  • New date operator: Added a new operator "is more than X days ago" for date filters, making it easier to filter products by relative dates.
  • Empty/not empty for dates: The "is empty" and "is not empty" operators are now available for date metafields and product publish dates.

June 30, 2025​

  • Root collection metafields: Added new metafields for storing up to 4 root collections, with updated theme extension support for better collection hierarchy management.
  • Date filter fix: Fixed the "relative last days" filter to correctly exclude future dates.

June 26, 2025​

  • Duplicate collections: You can now duplicate existing managed collections, making it faster to create similar collections with pre-filled conditions.

June 24, 2025​

  • Import/Export tool: Added a new import and export tool for managed collections (early access).

June 21, 2025​

  • Date and datetime metafield support: Added support for filtering on date and date_time metafield types.
  • Swedish language: The app is now available in Swedish.
  • Discount comparison operators: Added new operators to filter discounts by percentage - "less than X%" and "greater than X%".

June 20, 2025​

  • Collection creation improvements: Fixed redirect issues after creating collections and added a helpful banner suggesting you create another managed collection.
  • Better keyboard navigation: Improved keyboard interaction for condition groups and filters.

June 19, 2025​

  • Settings page: Added a new settings page where you can customize the app's homepage and choose which page you see when you first open the app.

June 18, 2025​

  • Warning for missing collection: If a collection is manually deleted from Shopify and was previously linked to a managed collection in the app, a warning message will now appear on the app's homepage. This helps you identify and fix managed collections that no longer have an associated Shopify collection.

June 16, 2025​

  • Search collections: We’ve added a text field to the managed collections list so you can search for the collection you’re looking for.

June 8, 2025​

  • New metafield support: We've added support for metafields that store metaobject and list of metaobjects. They can be used to filters products that have a given metaobject.

June 5, 2025​

  • Fixed tag filtering: When you use "is not equal" or "does not contain" for tags, the condition now correctly skips any product with at least one tag matching the condition.
  • Renamed and added stock filters: The old Inventory stock filter is now called Total inventory stock, and there’s a new Variant inventory stock filter so you can choose products based on the stock of each variant.

June 3, 2025​

  • Improved metafields search: When selecting a condition (product field or metafield), the list is now searchable. Additionally, product metafields and variant metafields are divided into two sections for easier navigation.

June 2, 2025​

  • New filtering operators: In addition to the existing operators such as "equal," "greater than," etc., we've added new operators "is empty" and "is not empty". They have been added for all metafields and the product field "compare-at price", allowing filtering of blank data.
  • New filter: We've added a new filter named "discount". It allows filtering product that are or are not on discount.

May 30, 2025​

  • Numerous performance improvments: Smart Collection Pro is now more stable for larger stores.

May 26, 2025​

  • New metafield support: We've added support for metafields that store booleans.

April 23, 2025​

  • New translations available: The app is now available in German, Dutch and Turkish.

April 21, 2025​

  • Better support for special characters: We've improved how the app handles characters from non latin scripts and special characters like French accents, the German “ß” (now matched with “ss”), and Turkish letters that use combined characters (like accented “g”), Asian scripts. This means searches and filters will behave more naturally across languages, including French, Czech, German, Turkish, Greek, Japanase, Korean, Chinese...

April 18, 2025​

  • Filter by product dates: You can now filter products based on their creation or publish date, making it possible to build, for example, collections that list products released in the last 30 days.

April 15, 2025​

  • New metafield support: We've added support for metafields that store decimals and integers.

April 3, 2025​

  • Smarter tag selection: Tag fields now suggest options as you type, so adding tags is faster and easier.

April 2, 2025​

  • New metafield support: We've added support for metafields that store lists of single-line text.

March 27, 2025​

  • New translations available: The app is now available in Czech, French, Italian, Spanish, Japanese, Korean, Danish, and Portuguese.
